# CV Search (MIF01)

A Java application developed as part of the **MIF01 – Software Engineering and Project Management** course at **Université Claude Bernard Lyon 1**.

The application assists recruiters in selecting candidates by comparing CVs against a set of required skills and applying different selection strategies. The project also focuses on software engineering best practices, including object-oriented design, design patterns, automated testing, and continuous integration.

## Technologies

- Java
- Maven
- JUnit
- GitLab CI/CD
